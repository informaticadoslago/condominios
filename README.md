# dosLago

Aplicación web (Laravel 12) de administración para dosLago: gestión de personas, usuarios, roles y permisos, catálogos maestros y copias de seguridad.

## Objetivo

Centralizar la administración de la entidad:

- **Administración de sistema**: personas, usuarios, roles, permisos, empresa y copias de seguridad.
- **Maestros**: entidades financieras, formas de pago y países.
- **Informes**: informes generados.

## Stack técnico

- PHP 8.4 · Laravel 12
- Livewire 3 + Flux (TallStackUI)
- Jetstream, Sanctum, Spatie Permission/Activitylog/Backup
